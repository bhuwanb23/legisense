# Asset Descriptions

No assets were captured — this project runs in text-only/no-capture mode per `BRIEF.md`
(no live website; the product is a Flutter app without a public marketing site).

All visuals are invented motion graphics built in LegiSense's own design language:

- **Brand tokens** (`capture/extracted/tokens.json`): ink #1A1A1A on white/#F7F7F7
  surfaces, chip #EEEEEE, hairline rules #E8E8E8, mute gray #8A8A8A, error red #B42318
  reserved for risk/danger highlights. Font: Plus Jakarta Sans.
- **Recreated UI motifs** (from the app's widgets, not screenshots): document cards with
  soft shadows and 20/32px radii, pill filter chips, floating black dock nav, risk gauge,
  clause list rows, chat bubbles with citation chips, deadline cards.

Asset inventory: none staged from capture. Frame workers build everything as HTML/CSS/SVG.
