# Legisense Backend

Minimal Express + TypeScript API scaffold. Feature routes will be added as we rebuild.

## Setup

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/health` | Health check |
| `GET` | `/` | Service info |

Default port: **3001** (`PORT` in `.env`).
