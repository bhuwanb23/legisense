# Design — Legisense (TripGlide Operate)

Locked system from studied TripGlide DNA. Brand remains **Legisense**.

## Genre

**modern-minimal / operate** — travel-app layout grammar applied to legal counsel tasks.

## Macrostructure

- Marketing / onboarding: Letter (bold greeting stack + black pill CTA)
- App Operate: Workbench (greeting, search+filter, chips, hero card, lists)
- Analysis: Long Document (sectioned cards on soft grey canvas)

## Theme

| Token | Hex | Use |
|-------|-----|-----|
| `bg` | `#F7F7F7` | App background |
| `surface` | `#FFFFFF` | Cards, search, sheets |
| `ink` | `#1A1A1A` | Text, black CTAs, floating dock |
| `mute` | `#8A8A8A` | Subtitles, hints |
| `chip` | `#EEEEEE` | Idle filter chips |
| `rule` | `#E8E8E8` | Borders |
| Risk colors | semantic | Scores only |

Always light.

## Typography

- **All UI:** Plus Jakarta Sans (Regular–Bold). Roman headers only.
- Never Spectral, Inter, Roboto, Arial as intentional brand faces.

## Layout & shape

- Screen padding ~24px.
- Hero / feature cards radius **32**.
- Search, chips, CTAs, dock = **pills**.
- Floating dock inset from edges (~20px), black pill, active icon in white circle.
- Soft single shadow; no gold accents; no paper/ivory editorial wash.

## Components

- **Primary CTA:** Ink fill, white Plus Jakarta Bold, height 56, pill; optional nested white arrow disc on hero CTAs.
- **Search:** White pill + mute search icon; adjacent black circular filter.
- **Chips:** Idle chip grey; active ink + white label.
- **Hero card:** Full-bleed visual (doc gradient), white meta overlay, black “Open analysis” pill + arrow disc.
- **Bottom nav:** Floating black dock — Home / Docs / Upload / Alerts / Profile.

Demo OTP: `123456`.

## Do's and Don'ts

**Do**
- Match TripGlide rhythm on Home first, then cascade identical chrome everywhere.
- Keep Legisense product copy.

**Don't**
- Ink & Trust paper/gold/Spectral.
- Soft sky washes, purple SaaS, cream+terracotta.
- Pixel-clone TripGlide travel photos or branding.
